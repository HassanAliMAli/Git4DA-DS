## 4. Technical Requirements for "Legendary" Accuracy
- **Simulated Reflog**: The terminal must track *every* action (even uncommitted ones), allowing for the `reflog` recovery challenge.
- **Worktree Simulation**: A UI that allows users to see multiple "Project Windows" mapped to different branches of the same repo simultaneously.
- **Data Quality Hooks**: A simulation of **Pre-Commit Hooks** that use `Great Expectations` to block a commit if the data drift is too high.
- **Signature Verification**: A UI element that shows the "Verified" green badge only when a commit is cryptographically signed.
